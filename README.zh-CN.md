## 项目简介

本项目基于 ESP32-S3-WROOM-1-N16R8 芯片，搭建一套支持本地触控、远程实时同步的智能家居 IoT 触控终端，完整实现"SPI 触控屏驱动、LVGL 图形界面、WiFi 配网、Home Assistant 双向通信、NVS 持久化存储、OTA 远程升级"全套方案。
硬件搭载 3.2 寸 320×240 电阻触摸屏（ILI9341 显示驱动 + XPT2046 触控驱动），软件基于 ESP-IDF 5.5.2 开发。
## 核心功能

1. **硬件底层驱动**
   - 分层 BSP 架构封装 SPI 总线，统一管理 ILI9341 显示屏、XPT2046 触控芯片；逻辑分析仪验证 SPI 时序稳定，最高 40MHz 刷新消除画面撕裂
   - 8MB PSRAM 大内存分配，专门缓存 LVGL 帧缓冲区、JSON 大数据，规避 ESP32-C3 无外置内存导致的内存溢出问题
   - FreeRTOS 多核任务隔离：核 1 运行 LVGL 图形任务，核 0 处理 WiFi、WebSocket、OTA 网络任务，任务优先级分级调度，保证触控无卡顿
2. **本地图形界面（LVGL v9.3 + GUI Guider）**
   - 可视化拖拽 GUI Guider 生成界面代码，共 6 大交互页面：主页、WiFi 配置、HA 设备绑定、OTA 升级、系统设置
   - 界面与业务完全解耦：UI 仅全局状态只读，通过 LV 定时器刷新，杜绝多线程并发崩溃
   - 多设备控制、气象数据实时展示、WiFi 状态可视化，自动切换天气图标（晴天 / 多云 / 雨天）
3. **WiFi 配网模块**
   - STA/AP 双模式自动切换：无保存配网信息时自动开启 AP 热点，内置 Web 配网页面
   - Web 端表单一键填写 WiFi 账号、Home Assistant IP/Token，参数自动存入 NVS 持久化
   - 有限状态机 (FSM) 管理 WiFi 连接，自动重连、断网容错，配网完成自动关闭 AP 降低功耗
4. **Home Assistant 混合双通道通信（核心方案 v4.0）**
   - 摒弃单一 MQTT/HTTP/WebSocket 缺陷，采用**HTTP + WebSocket 混合双信道架构**
   - WebSocket 长连接：低延迟双向实时控制设备，订阅设备状态变更，无轮询 CPU 占用
   - HTTP 短连接：设备初始化批量拉取全部实体信息，仅启动时调用，节省长连接带宽
   - cJSON 内存重定向至 PSRAM，解决大 JSON 解析造成的 DRAM 内存碎片、设备死机问题
5. **非易失存储 NVS**
   - 独立命名空间存储 UI 绑定设备 ID、HA 连接参数，断电配置不丢失
   - 独立 NVS 写入任务队列，UI 操作不阻塞界面，异步持久化防止栈溢出
6. **OTA 远程固件升级**
   - 两套升级方案：本地 HTTP 检测、云平台 MQTT 检测固件版本
   - 分块下载固件，实时 UI 展示下载进度，升级失败自动回滚，防止变砖
7. **低延迟远程触控同步**
本地触控事件实时通过 WebSocket 上传 HA，设备状态秒级下发同步，端到端延迟最低 100ms，平衡 CPU 负载与实时性。
